Class HealthController

Controller handling health check endpoints

This controller provides REST endpoints for system health monitoring, including basic health checks and detailed system status information.

Remarks

The health check endpoints are designed to be used by monitoring systems and load balancers to determine the health of the application.

Example

const controller = Container.get(HealthController);
const health = await controller.checkHealth({ full: true });
