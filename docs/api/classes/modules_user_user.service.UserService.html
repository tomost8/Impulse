Class UserService

Service handling user-related business logic

This service provides methods for managing users in the system, including CRUD operations and user-specific business logic.

Remarks

Uses Prisma as the ORM for database operations

Example

const userService = Container.get(UserService);

// Create a new user
const newUser = await userService.create({
  email: "john@example.com",
  name: "John Doe"
});
