Class User

User entity representing a user in the system

This class defines the structure of a user and is used both as a GraphQL type and a database model.

Remarks

All fields marked with @Field are exposed in the GraphQL schema

Example

const user: User = {
  id: 1,
  email: "john@example.com",
  name: "John Doe",
  firebaseUid: "firebase123",
  createdAt: new Date(),
  updatedAt: new Date()
};
