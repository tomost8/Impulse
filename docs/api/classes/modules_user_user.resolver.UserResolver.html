Class UserResolver

GraphQL resolver for User-related operations

This resolver provides the GraphQL API endpoints for user management, including queries and mutations for CRUD operations.

Remarks

All methods are automatically exposed in the GraphQL schema through type-graphql decorators.

Example

# Query all users
query {
  users {
    id
    email
    name
  }
}
